AbrikosovSimulation — версия с внешним прямоугольным магнитом

Сборка (если Raylib и CMake установлены):
    cmake -S . -B build
    cmake --build build -j

Запуск:
    ./build/AbrikosovSimulation

Во вкладке MAGNET можно включать/выключать магнит, менять его X/Y/Z,
силу и ориентацию. Магнит должен оставаться снаружи куба (образец имеет
границы примерно X/Y = +/-10 и Z = +/-6). Золотые отрезки показывают
направление поля в нескольких точках, а красный/синий маркеры — полюса.

Физическая оговорка:
Это качественная демонстрационная модель. Магнитное поле рассчитано
приближением точечного диполя, а воздействие на вихрь — через градиент
компоненты Bz. Это не полноценное решение уравнений Гинзбурга–Ландау
и не расчёт поля с учётом экранирования сверхпроводником.
